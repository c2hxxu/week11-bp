# 느린 황금시간 : created by 홍길동

바로크 분위기의 카페와 운영자를 소개하는 반응형 단일 페이지 홈페이지입니다. HTML, CSS, JavaScript만 사용하며 별도의 프레임워크나 패키지 설치 없이 실행할 수 있습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 별도의 빌드나 서버 실행은 필요하지 않습니다.

## 주요 기능

- 카페와 운영자 소개, 메뉴, 찾아오시는 길을 한 페이지에서 확인
- 메뉴를 커피·차·디저트 종류별로 필터링
- 헤더 버튼으로 라이트 모드와 다크 모드 전환
- 모바일 화면용 메뉴 버튼과 반응형 레이아웃
- 키보드 포커스 및 버튼 접근성 속성 제공

테마는 페이지를 새로 열면 라이트 모드로 시작합니다.

## 파일 구성

```text
week11/
├── index.html   # 홈페이지 마크업, 스타일, 동작
├── hello.js     # Git 실습용 JavaScript 파일
└── README.md    # 프로젝트 안내
```

`index.html` 안에 페이지 구조와 CSS, JavaScript가 함께 있습니다.

## 내용 수정

메뉴 이름과 가격, 소개 문구, 영업시간 및 연락처는 `index.html`에서 직접 수정할 수 있습니다. 주소, 이메일, 전화번호는 예시이므로 실제 사용 전에 원하는 정보로 바꿔 주세요.
